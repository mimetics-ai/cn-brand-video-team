# 角色设定卡（Character Sheet）· v1.6.0

> **用途**：多集 / 多角色任务，**必须先填这张卡，再动手**。
> **纪律**：AI 模型的"人物一致性"靠不住（脸会变/衣服会变/发型会变），
> 我们用**工程流程**顶住：**固定字符串前缀 + 每次注入**。

---

## 一、为什么需要这张卡（实证依据）

**某真人片项目B实测**：
- 定妆图试了 **≥6 版**（女/男/职业女性A/A2/A3/情境B）
- **抬臂 4 版**、抬臂露腋 4 版、握姿 ≥2 版（名字里写"修正"）
- 跨集/跨镜的**人物漂移是必然**，不是偶发

⇒ **不靠模型记住，靠我们每次把它"念一遍"。**

---

## 二、角色卡模板（每个角色一份，复制使用）

```markdown
# 角色卡：<角色名>

## 1. 长相（**逐字固定，不许改写**）
- 性别/年龄：
- 脸型：
- 发型（长短/刘海/发色）：
- 肤色/肤质：
- 眉眼（形状/浓淡）：
- 是否戴眼镜/饰品：

## 2. 服装（**每集可换，但一集内不许换**）
- 上衣（颜色/材质/领型）：
- 下装：
- 鞋：
- 配饰（表/包/戒指）：

## 3. 说话习惯（**决定配音与字幕口吻**）
- 语速（快/中/慢）：
- 口音/方言：
- 高频词（如"其实吧""说白了"）：
- 语气（亲和/专业/冷）：
- 称呼客户/用户的方式：

## 4. 固定 Prompt 前缀（**每次生图/生视频必须原样贴**）
```
<把 1 和 2 压缩成一句，60–100 字>
例：35岁中国女性，鹅蛋脸，齐肩黑直发无刘海，暖白皮，

## 5. 首帧图（R1 铁律：必须真人截图或授权定妆照）
- 定妆图路径：
- **授权状态**：自有 / 客户提供（需书面同意）/ 来源不明（**禁用**）
- 首帧验收：≥1080 宽 ／ 面部无遮挡 ／ 构图与目标镜一致

- v1 ｜ 建立日期 ｜ 最后修改 ｜ 修改原因

## 三、★ 强制注入纪律（**这是整套方案的核心**）

### 三条铁律

| # | 铁律 | 违反后果 |
|---|---|---|
| **1** | **多集/多角色任务，开工前必须先有角色卡** | 没有卡 = 每镜重赌一张脸 |
| **2** | **每次生图/生视频，**必须把卡片第 4 节的固定前缀**原样贴在提示词最前面** | 不贴 = 模型自由发挥 |
| **3** | **同一集内服装不许换**（跨集可换，但要在卡里登记"第几集换什么"） | 换了 = 观众认不出是同一个人 |

### 注入格式（**照抄，不许改顺序**）

```
<角色卡固定前缀>，<本镜的动作提示词（W6 五铁律）>
```

**例**：
```
35岁中国女性，鹅蛋脸，齐肩黑直发无刘海，暖白皮，眉形细长，不戴眼镜；
米白色棉质衬衫（小翻领），深灰直筒裤，无配饰。
机位完全固定，不做任何推拉摇移。首帧中的女性保持站立姿态，
只做很轻微的自然动作，呼吸起伏可见。
```

> **顺序不能倒**：**人物在外、动作在后**。
> 反了（先写动作后写人物），模型会优先保证动作而牺牲长相。

## 四、多集/多角色时的额外规则

| 场景 | 规则 |
|---|---|
| **同一角色跨集** | 用**同一张首帧图**（或同一定妆照）驱动 ⇒ 比重生成靠得住 |
| **同集多角色** | **每镜只让一个人动**；两人同框时，另一人写"保持原姿势不动" |
| **角色换装** | 在卡里记"第 N 集换成 X"，**同集内不许换** |
| **角色说话** | 语速/口音/高频词**写进卡**，交给配音环节统一（否则每集语调不同） |

---

## 五、交付说明里要写什么

必须附一段：

> **角色一致性方案**：本片共 N 个角色，均使用角色卡（固定 Prompt 前缀 + 同一首帧图）。
> **已知限制**：AI 生成的人物在**表情细节、手部、多人交互**上可能与真人存在差异（行业瓶颈），
> 我们已通过"**固定前缀 + 同首帧 + 单镜单人**"降低漂移，**但不能保证 100% 一致**。
> 如需严格一致，建议**实拍**。

## 七、★★ 四维一致性：道具 / 场景 / 色调（v1.6.0 补 · **脸之外的三件事**）

> **背景**：一致性不只是脸。跨镜头变的不止长相 ——
> 瓶子比例变了、办公室窗外变成了夜景、这一镜暖下一镜冷，**观众一眼就出戏。**

### ① 核心道具说明（**每个出现 >1 次的道具填一份**）

```markdown
# 道具卡：<道具名>

- **外观**：形状 / 高度 / 直径 / 瓶盖类型
- **颜色**：主色（附色号或参考图）/ 辅色 / 标签底色
- **材质**：玻璃 / 塑料 / 金属 / 哑光 / 高光
- **Logo 位置与大小**：正面居中 / 高度占比 __%
- **参考图**：（**必须有**，见下）

## ★ 铁律：道具用**参考图**，不用文字描述
- 文字写"白色磨砂瓶"，模型每次生成的磨砂程度都不同
- **用同一张产品图做参考**（图生图 / 首帧带产品），比例和材质才锁得住
- 若模型支持"主体库/Element"（如可灵），**把产品注册成主体**再复用
```

### ② 核心场景说明（**每个出现 >1 次的场景填一份**）

```markdown
# 场景卡：<场景名>

- **空间类型**：办公室 / 车间 / 街道 / 家居
- **背景元素清单**（**逐项列出，不许"等等"**）：
  1. 左后方：__（例：三格文件柜，灰白色）
  2. 右后方：__（例：落地窗，百叶帘半开）
  3. 地面：__（例：浅灰环氧地坪）
- **光源方向**：主光在__（例：画面左前方 45°）/ 色温__K / 是否逆光
- **时间设定**：上午 / 下午 / 夜（**同一场景不许改**）
- **参考图**：（**必须有**，同一空间的多机位参考）
```

### ③ ★ 全局色调（**全片只有一次决定权**）

```markdown
## 本片全局色调（**开工前定，全片不改**）

- **倾向**：暖调 / 冷调 / 中性
- **色温**：__K（例：5200K 偏暖）
- **对比**：低对比（柔和）/ 中 / 高对比（硬朗）
- **饱和度**：低饱和（高级灰）/ 中 / 高饱和
- **暗部倾向**：偏青 / 中性 / 偏褐
- **统一手段**：**所有镜头出片后过同一套 LUT / 同一组调色参数**
```

> **★ 为什么必须"全片一次定"**：
> 模型每次生成的白平衡都不同，**不靠统一调色，剪在一起就是"两个片子拼接"。**
> ⇒ **生成时靠提示词对齐，出片后靠同一套调色兜底。两道都要。**
