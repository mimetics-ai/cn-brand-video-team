# AI 真人提示词模板库（10-26 复盘补 · 源自某真人片项目B 15 条 + 《某短剧项目C》短剧 22 镜实证）

> 用法：复制对应段落，把 `<>` 里的内容换成你的场景。**五条铁律不得删改** ——
> 但它们只约束 **1–10 条（人物微动类，品牌口播/半身镜）**；
> **11–13 条与负面清单、静图锚点工作流属于「叙事片动作类」，不受"机位完全固定"限制**，
> 按各自段内说明执行。

## ★ 五条铁律（每条提示词必须包含前三条）

1. **机位完全固定，不做任何推拉摇移**
2. **以「首帧中的<人物>」或「保持原姿势」开头**（锁姿态）
3. **只做极轻微的自然动作**（呼吸起伏 / 头部 N 度 / 在已有表情基础上）
4. **动作次数写死**（如「全程只有一次」）
5. **首尾帧同表情**（便于循环与衔接）

## 1. 开场 · 站立

```
机位完全固定，不做任何推拉摇移。首帧中的<职业>女性保持站立姿态，
全身几乎不动，只有呼吸起伏。表情平静，直视前方偏下 5 度。
```

## 2. 通勤 · 极缓推

```
机位固定，允许极缓慢向前推进，推进幅度不超过 3（刻度/百分比）。
首帧中的女性原姿势保持，只做很轻微的自然动作。
```

## 3. 侧身 · 留后期位

```
机位完全固定，没有任何推拉摇移。她侧身站立，身体和肩膀全程几乎不动，
只有轻微呼吸。构图右侧留空，以留给后期叠加产品。
```

## 4. 看报告 · 空白占位

```
机位完全固定，不做推拉。她双手在胸前拿着那张空白的白纸，
纸面朝向镜头、不遮挡脸。只有极轻微的自然动作。
```

## 5. 松弛 · 微抬头

```
机位完全固定，不做推拉，中近景。她的头部微微抬起约 5 度，
肩膀轻微下沉，只有呼吸起伏，全程只抬一次。
```

## 6. CTA · 直视镜头

```
机位完全固定，没有任何推拉摇移。她直视镜头，
全程只有一次轻微点头（不超过 5 度），然后保持。
```

## 7. 抬臂 · 硬约束

```
机位完全固定，没有任何推拉摇移。最关键的约束：她抬起的手臂
不超过肩膀高度，手肘不越过身体中线，全程只抬一次，抬起后保持不动。
```

## 8. 表情强化（微笑）

```
机位完全固定，不做推拉摇移，中近景。她在已有微笑的基础上，
嘴角轻微上扬（幅度极小），眼角先动、嘴角后动。首尾帧是同一个表情。
```

## 9. 道具交互（喷雾/拿取）· 极轻微

```
镜头固定不动，人物保持原姿势，只做极轻微的自然动作。
手持<道具>，动作幅度不超过 10 厘米，全程只有一次动作，之后保持。
呼吸起伏可见。
```

## 10. 微动兜底（不确定时用这条）

```
镜头固定不动，人物基本保持原姿势，只做很轻微的自然动作。
```

# 手部 / 道具 / 无人镜（10-26 复盘补 · 源自《某短剧项目C》短剧 15 镜实证）

> 上面 1–10 条都是「人物微动」。**叙事片真正难的是"手做一个动作"和"没有人"**，单列如下。

## 11. 手 · 道具落位（最常用）

```
保持画面构图、人物、光线与参考图完全一致，不要切换镜头。画面中不要出现任何文字字幕水印。
动作：手腕极缓慢地一转，杯底稳稳落在木桌面上，杯里的茶水表面晃了一下随即稳住，
手停留在杯边两秒才缓缓收回。镜头极缓慢地向茶杯推近。
暖调侧光，胶片颗粒，克制。手部解剖结构正确。
```

**结构固定为四段**：`锁画面` + `一个动作（含幅度与节奏）` + `一个运镜（或不运镜）` + `质感与解剖校正`。
「手部解剖结构正确」这句实测有效，别省。

## 12. 空镜 / 无人镜

```
动作：画面里没有任何人和动作，只有那道从窗外射进来的光柱极其缓慢地在旧桌面上移动，
光柱里的浮尘缓缓飘浮；笔记本的卷边在光里投出细微的影子。镜头极缓慢地横向平移。
```

**必须明写「画面里没有任何人和动作」**——不写，模型会自己往画面里塞一个人。

## 13. 同一动作拍两次（对仗镜）· 必须用「常量」

叙事片的题眼常常是「他做一次，我做一次」。要让两次落杯**力道与节奏一致**，
做法不是反复调参，而是：**把动作段写成一段逐字相同的常量文本，两次只换参考静图**。

```python
CUP_ACT = ("动作：手腕极缓慢地一转，杯底稳稳落在木桌面上，杯里的茶水表面晃了一下随即稳住，"
           "手停留在杯边两秒才缓缓收回。镜头极缓慢地向茶杯推近。"
           "暖调侧光，胶片颗粒，克制。手部解剖结构正确。")
# 镜 B3：他的手（参考静图 b3.png）
# 镜 B7：我的手（参考静图 b7.png）—— 动作串完全相同
```

> 改一个字，落杯的节奏就会变，对仗立刻不成立。**常量不是代码洁癖，是拍法。**

# ★ 负面清单：这些别写，换个拍法（10-26 复盘补 · 逐条实测）

| 做不到的写法 | 实测表现 | 替代拍法 |
|---|---|---|
| 「五指并拢」当**静态姿态** | 三次全废：静态图里手指永远画不对 | 它是**动作**不是状态——写进**视频** prompt「手指缓缓收拢」，实测 4/4 成 |
| 液体**动态泼溅**（打翻牛奶、水花） | 必假：对称白环 + 悬浮液滴，像特效贴纸 | 改**静态浸染**——液体慢慢洇开纸面/布面，极真 |
| **两只手**同时做精细动作 | 崩概率远高于一只手 | **只给一只手**，另一只手出画或压在画面外 |
| 脚与脚趾（尤其光脚、倒影里的脚） | 脚趾会画成手指 | 三板斧：**只拍鞋不拍脚** ／ 负向写「不露出任何脚趾」／ **弃倒影** |
| 水面 / 玻璃**倒影**里的人物 | 概念理解差，会画出"第三个人"或光脚 | 改**第一人称俯视 POV**（实测效果超预期，是意外收获） |
| 屏幕 / 招牌 / 书页上的**字** | 必糊、必乱码 | 后期叠；画面里留空位 |
| 无人镜**不写"没有人"** | 模型自己塞一个人进去 | 明写「画面里没有任何人和动作」 |
| 白纸 / 试卷 / 单据当**叙事道具** | 特写里永远是白纸（试卷没分数=叙事漏洞） | prompt 写明**具体内容**：「纸上是红笔批改的分数和叉」 |
| 屏幕 / 仪表只写"仪表盘" | 数值乱码且与剧情矛盾 | 写明**具体数值与单位**（心率 29、血氧 97），后期校对 |
| 20s 以上叙事**一次生成** | 后段一致性崩、硬伤累积 | **分段生成**（实测平台故事模式 96s=5 段），段间设计**动作钩子**衔接 |

### 大环境小人物（v1.8.0 · T6 参考视频技法吸收 · 构图章补充）

需要「人融进大场景」的意境镜头（城市/山野/人流）时，人物**只写**：「远景小人＋剪影级描述＋**一个动作**」，**禁写五官衣着细节**。人物占比小 ⇒ 畸形不可见 ⇒ 天然规避露脸与跨集同脸。项目级黑名单（`_compliance_watchlist.md`）优先于本语汇。

# ★ 平台故事模式实证（10-27 补：对标一条 96s 成片）

- 即梦 App「小说/短剧模式」一条出了 **96s / 19 镜 / 同一演员正脸表演**，实为 **5 段生成**拼接；
  自带环境音床与 3 句台词、自带 AIGC 合规元数据。平均镜长 5.1s（与我们 6s/镜同量级）。
- **硬伤率约 1/4**：乱码文字、数值矛盾、物理因果断裂、人脸跨场景漂移、手指破绽——
  全部集中在"模型自己负责"的部分；修片手法见 `repair_kit.md`，可零积分修掉大半。
- **结论**：正脸单集叙事**可试制**（分段控制一致性），但「能出一版 ≠ 能稳定交付」，
  对外只承诺「试制+逐镜验收」，不承诺效果，不碰跨集同脸与量产。

# 静图锚点 + 动作 prompt 工作流（10-26 复盘补）

**为什么不能「文生视频直接写场景」**：同一段场景描述跑两次，会生出两个不同的人、两套不同的光。
正确顺序是四步，一步都不能跳：

1. **出静图**：把人物、光影、构图、道具位置一次锁死（静图成本约为视频单镜的 1/23，按当时价目折算）
2. **人眼过静图**：查比例、手指、脚、文字、道具数量——**静图阶段改一张几乎不要钱，视频阶段废一镜就是一份成本**
3. **视频 prompt 只写两件事**：一个动作 + 一个运镜，前面加「保持与参考图完全一致，不要切换镜头」
4. **同一场景的所有镜头共用同一张静图当锚点**（i2i 接同一张定妆图），跨镜一致性靠图锁，不靠文字

> 实测：7 张静图一次过 → 7 镜视频一次过（7/7）；另一轮跳过静图直接出视频前，3 张静图连续栽在"脚"上。

## 生成参数建议

| 项 | 建议 |
|---|---|
| 单段时长 | **5 秒定长**（某真人片项目B 15 段全部 5.00 s —— 超过 5 秒误差累积） |
| 实际帧数 | **不要信容器 `Duration`**：实测标称 5.16 s 实际只有 120 帧（4.98 s）。**剪辑前先数帧**，时间轴按 `frames/fps` 算 |
| 分辨率 | 1080×1920（9:16 竖版） |
| 驱动方式 | 首帧图 → 动作迁移／文生视频（**优先首帧锁定**） |
| 不满意处理 | **重生成并加 `_v2`**（某真人片项目B"开心"就出了 v2 —— 一次不成是常态） |

- [ ] 手指数量与关节方向正常
- [ ] 无多余肢体、无肢体穿身
- [ ] 表情不僵直（连续 3 帧有微变化）

- [ ] 首尾帧表情一致

## 12. ★ 故事改编四律（武侠短剧实战复盘 10-28 · 叙事片/短剧必读）

> 实战背景：《雪夜医女》十集 101s 全 AI 生成交付。以下四条是翻车换来的，叙事片/短剧一律执行。

### 律一 · 对白 ≠ 旁白
- 故事里有对白，**必须保对白**（角色声纹 TTS + 烧录字幕），**禁止**压成旁白、禁止整段丢弃。
- 对白镜头三选一：**说话人正脸 / 过肩 / 听者反应镜头**。刻意「只闻声不见人」必须是设计（悬念/画外威压），并在分镜标注「设计留白」。
- **翻车实证**：第 8 集「我的仇，我自己报」台词响着、画面是空雪堆——观众读成旁白，情绪全失。

### 律二 · 情绪 = 表达方式 + 面部表情
- 每句对白标【情绪】，并**同时**落到两处：TTS（rate/pitch 偏移）＋ 画面 prompt（含泪/咬牙/眼眶泛红/下颌绷紧）。
- 表情与台词**必须同向**：哭腔配微笑 = FAIL（审查按对位查，见 repair_kit 第 12 项）。
- 静图锚点生成时把情绪写进首帧描述——「在已有表情基础上」不适用于情绪转折镜，情绪转折镜首帧直接画目标情绪。

### 律三 · 动作设计与布景连续性
- 每镜一个**主动作 beat**＋起止状态；动作先过**安全审核预判**：刺/杀/砍/血 → 替换动作库（挡在剑前 / 剑偏擦出手臂 / 剪影 / 出手前定格）。
  **实证**：第 9 集「剑刺入身体」首帧连续 3 次生成被安全审核拒，改「她张开双臂挡在剑前」一次过。
- 布景表跨镜核对：天气 / 光源方向与色温 / 道具位置 / 服装破损程度。破了的袖子下一镜必须还破着。

### 律四 · 流畅衔接三查
- **方向**：180°轴线不跳（A 在左，切镜后 A 还在左）。
- **光线色调**：相邻镜色温跳变超一档 = 硬伤（夜景切暖阳）。
- **景别递进**：远→中→特可以，特→远→特慎用。
- 工程纪律：段内**禁用 fps 重采样滤镜**（每段掉 1 帧，243→242）；闪回/插入段**真切段进 concat**，overlay+tpad 模拟不生效。

### 12b. VideoGen 实测参数坑（本机 10-28）
- `aspect_ratio` 参数被忽略：横片恒出 1152x768(3:2)，竖片恒出 768x1152(2:3) ⇒ **按目标画幅预先规划裁切窗口**（横片上下各裁 60px；竖片 crop=638:1134:130:9）。
- 输出**自带双水印**（左上＋右下）：裁切窗口避左上，右下用不透明标识覆盖（我们本来就要烧 AI 标识，正好压位）。
- 10s 单段上限可用；原图水印裁掉后必须重烧。
