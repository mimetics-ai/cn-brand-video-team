# 电影分镜型镜头生成模板（v1.6.1 · 短剧/对白片专用）

> 定位：把「小说叙事型」生成改造为「电影分镜型」。
> 适用：W8 叙事片/短剧的**对白档**。品牌口播片不受此模板约束（走 `ai_live_action_prompts.md` 模板 1–10）。
> 实证依据：2026-10-28《雪夜医女》十集复盘——对白被压成旁白、情绪形容词产出面瘫脸、
> 动作木偶感、整段生成画面卡顿，四类翻车后才立本模板。

## 模块一 · 提示词模板（每镜五件套，顺序不能倒）

```
<角色外观锚点（角色卡固定前缀，含≥1处具体锚点，如"左眉尾小痣/右手背旧疤"）>，
<主体与景别（如"中景，沈青禾半蹲在雪地"）>，
<动作（写到关节+速度，查模块三替换表，只写一个主动作）>，
<单一运镜（模块三五选一，只写一种）>，
<风格与光线（与全片色调前缀一致）>，
<统一负面词（模块五 17 项整段照抄）>
```

**五条硬规则**：

1. **禁止在提示词里写台词**——生成器会试图对口型，口型必不同步且拖慢动作。
   台词一律后期 TTS + 烧字幕（见 `agents/audio-designer.md` 对白 TTS 规则）。
2. **角色外观锚点必须来自角色卡第 4 节固定前缀**，逐字照抄，不得即兴。
3. **每镜只写一个主动作**——两个以上动作，模型会平均分配幅度，两个都假。
4. **禁止笼统动词**（挣扎/包扎/后退/抬头单独出现），见模块三替换表。
5. **禁止情绪形容词**（痛苦/愤怒/震惊），表情改写肌肉动作，见模块四。

## 模块二 · 工作流（五步，闸不过不进下一步）

| 步 | 做什么 | 硬闸 |
|---|---|---|
| 1 定妆 | 每角色 1 张定妆参考图（画幅按片），登记进角色卡 | 无定妆图不开工 |
| 2 关键帧 | 每镜先出关键帧静图（构图/姿势/道具位），人眼逐张过 | 静图不过不进视频（一镜视频≈23 张静图的成本） |
| 3 图生视频 | 关键帧 + 角色参考图**共同喂**图生视频 | **禁纯文生视频、禁整集生成、禁多镜合并**；接口禁同喂时（实测 10-28 minimax 通道拒「首帧+参考图」），参考图前置到关键帧阶段，i2v 单喂首帧 |
| 4 候选择优 | 每镜 3 个候选，按模块六评分选 1 | 手指异常/锚点错位/动作抖的候选直接淘汰 |
| 5 台词后期 | TTS 台词轨 + 烧字幕 + 逐窗对位；口型不生成、靠后期覆盖 | 对白对位（`repair_kit.md` 第 11 项） |

> **三禁不分档**：对白片一律适用。依据：整段生成版实测卡顿闪烁率显著高于单镜段；
> 纯文生视频每一镜都在重赌人物长相。

## 模块三 · 运镜与动作库

**每镜只允许一种运镜**，五选一：
`固定` ／ `缓推` ／ `缓拉` ／ `微移` ／ `快速平移急停`
（两种以上 = 复合运镜 = 负面词「复合运镜」命中，直接判废。）

**动作颗粒度替换表**（左禁右替）：

| ❌ 笼统（禁用） | ✅ 关节+速度（照这个写） |
|---|---|
| 痛苦地挣扎 | 右手五指抠进雪里，指节发白，两次，每次约一秒 |
| 温柔地包扎 | 双手拇指压住布条一端，绕腕一周，中途停顿半秒看伤口 |
| 愤怒地拔剑 | 左手按鞘，右手虎口扣柄，前推出鞘约 15 厘米，急停 |
| 惊恐后退 | 右脚后撤半步，膝盖微屈，双手仍端药碗，碗面微晃 |
| 缓缓抬头 | 下颌先收，颈部带动头抬起约 30 度，全程约 2 秒 |

写法三要素：**哪个关节 + 幅度/轨迹 + 速度或次数**。缺一即退回。

## 模块四 · 肌肉级微表情库（禁情绪形容词）

每个表情**至少两条肌肉动作**，直接写进画面提示词：

| 情绪 | 肌肉动作（照抄或组合） |
|---|---|
| 恨 | 眉毛中段下压、上眼睑微抬盯住目标；咬肌绷紧，嘴角单侧下拉 |
| 隐忍 | 嘴唇抿紧发白、下颌微收；眨眼频率明显降低，呼吸起伏放缓 |
| 震惊 | 眉毛快速上扬、上眼睑抬起露白；嘴唇微张但不发声，颈部后缩半寸 |
| 悲 | 眉毛内侧上挑、眉心聚拢；上眼睑下垂，视线落向下方 |
| 警惕 | 眼球先于头部转向声源；眉毛保持平位，鼻翼轻微扩张 |
| 柔和 | 眼轮匝肌放松，下眼睑微微上抬；嘴角对称上提不露齿 |

> 依据：情绪形容词（"她震惊地看着"）实测产出面瘫或夸张脸；肌肉动作是模型可执行的物理指令。
> TTS 情绪与画面表情必须同向（`repair_kit.md` 第 12 项情绪对位）。

## 模块五 · 统一负面词库（17 项，每镜整段照抄）

```
肢体畸形，五官扭曲，画面闪烁，动作卡顿，画面撕裂，多余手指，手指粘连，
画面模糊，画质粗糙，口型不同步，旁白感，静帧，人体结构错误，自动字幕，
烧录文字，镜头跳变，复合运镜
```

- 逐镜可**追加**镜头专属负面词（如水面倒影镜加「倒影扭曲」），但**不得删减** 17 项。
- 「口型不同步」「旁白感」「自动字幕」「烧录文字」四项是**对白片专用**——
  它们堵的是「生成器自己配音配字幕」这条路，与模块一第 1 条配套。

## 模块六 · 参数与重试

**候选评分（每镜 3 候选，按 4 维打分选 1）**：

| 维度 | 目标值 | 实际操作 |
|---|---|---|
| 动作平滑度 | 88–92 分区间 | 逐候选抽帧看动作中段，抖动/跳变者淘汰 |
| 骨骼约束 | 7（0–10） | 对照「人体结构错误」：关节反折/躯干扭转即扣到底 |
| 手指 | 手指正常 | 逐帧查手指数量与粘连（首要淘汰项） |
| 锚点 | 疤痕/痣等锚点在且位置对 | 不对直接淘汰 |

> ⚠️ **参数注记**：即梦 CLI 当前接口不直接暴露「平滑度/骨骼约束」数值参数（实测 2026-10-28）。
> 上表数值作为**候选评分维度**执行——即"按 88–92 分标准在 3 候选里选"；接口若后续暴露同名参数则直接代入。
> **平滑度与骨骼约束参数在接口不支持时仅作候选评分维度，不得视为已生效控制。**
> 成本口径：720P 14 积分/秒（happyhorse_1.1）、18/秒（seedance_2.5），3 候选 = 单镜成本 ×3，
> **报价按此计**（记 `budget_ledger.md`，含重试次数）。

**重试梯度（不通过按序执行，不得跳步）**：

1. **先改图生视频**：换关键帧（改姿势/构图），不动提示词语义
2. **减动作**：动作幅度/次数砍半（"两次"→"一次"）
3. **提参考权重**：角色参考图权重上调（接口支持时）或改更近景别
4. **换候选**：3 候选全废 ⇒ 回第 1 步，最多循环 2 轮；仍不过 ⇒ 报主理人改分镜

> 不许「同一提示词原样重跑」——同输入同输出，重跑不是重试。

## 模块七 · 输出格式（逐镜七段，缺段即退回）

```
【镜头编号｜时长】S01 ｜ 5.0s（帧数按 fps×时长，fps 全片统一 24）
【画面提示词】<模块一五件套全文>
【负面提示词】<模块五 17 项整段 + 镜头专属追加>
【后期字幕台词】<逐句：台词｜说话人｜TTS 声线/rate/pitch｜是否露脸（在镜/设计留白）>
【音效建议】<环境音/音效/静默设计，逐镜一条>
【验收标准】<本镜专属：动作 beat 完成点/锚点在位/无负面词命中/帧数实测>
【失败重试策略】<预设本镜最可能的失败模式与对应梯度步骤>
```

- 交付为**逐镜七段**，禁止小说式段落（"雪夜里，他挣扎着……"一律退回）。
- 全片断言仍有效：旁白占比 ≤45%、首镜 3 秒内有疑问或动作、对白单列成表。

## 验收清单（八项，逐镜 + 全片各过一遍）

1. **对白未压成旁白**：对白轨独立成表，旁白轨只做串场
2. **台词零生成**：成片无生成口型台词、无自动字幕；台词全部后期 TTS + 烧录
3. **表情肌肉级**：每个表情镜头 ≥2 条肌肉动作描述，全片无情绪形容词
4. **动作关节级**：每个动作有关节+幅度+速度三要素，无笼统动词
5. **单运镜**：每镜仅一种运镜，无复合运镜
6. **负面词齐全**：每镜负面词含 17 项整段，生成后抽帧无命中
7. **三候选择优**：每镜 3 候选留痕，选中者手指正常/锚点在位/动作平滑
8. **帧数实测**：逐镜实测帧数与时长（容器 Duration 不可信，按 frames/fps），自检 PASS
