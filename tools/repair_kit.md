# ★ 成片急救箱（10-27 补：即梦参考片审核+修复实战沉淀）

> 一条生成的片子有硬伤，**先修后重生成**。实测一条 96s 叙事片 5 处硬伤全部修复，**零积分**；
> 重生成一条 5s 视频就要 70 积分。修 vs 重生成是 23:1 之上的杠杆。

## 一、审查十项（成片交付前逐帧过一遍，两小时以内的片子值得）

按接触印相（每 2s 一帧拼 3x3）+ 可疑段 0.5s 细扫 + 放大裁切三层看：

| # | 查什么 | 典型翻车 |
|---|---|---|
| 1 | **文字**：招牌/品牌/屏幕/书页 | 全是乱码假字（无法避免，只能后期盖） |
| 2 | **数值自洽**：仪表/监护仪数字与剧情 | 心率 29 濒危但血氧 97、波形有力 |
| 3 | **物理因果**：液体/破碎/坠落 | 杯还在桌上、地上已炸开泼溅（因果断裂） |
| 4 | **人脸一致性**：同一角色跨场景 | 同衣不同脸（判不清是 bug 还是剧情就问客户） |
| 5 | **手指**：特写手逐帧数指 | 缺指/多指/游离指尖/过长指节 |
| 6 | **走位眼线**：A 看 B，切镜后 B 在哪 | 看着孩子坐下、孩子却到了背后 |
| 7 | **空间方向**：运动镜头的进出方向 | 向镜头跑→突然背对镜头（方向翻转） |
| 8 | **道具内容**：纸/书/单据特写 | 白纸一张（试卷没分数=叙事漏洞） |
| 9 | **入画时机**：该在远处的角色何时出现 | 说"跑出去抱孩子"孩子却已在旁边 |
| 10 | **音频**：逐窗 RMS + 台词对位 | 错位/计划外静音/台词与画面不同步 |
| 11 | **对白对位**：每句台词说话人是否在镜 | 台词响着画面无人（第8集空雪堆）；在镜却口型完全静止于长句 |
| 12 | **情绪对位**：表情与台词/剧情同向 | 哭腔配微笑；「我恨你」面无表情；TTS 情绪与画面表情各走各的 |

### 分镜档八项验收（v1.6.1 · 对白片走电影分镜型时附加）

对白片/短剧按 `tools/shot_prompt_template.md` 生成的，其末尾**八项验收清单**
（对白单列/台词零生成/肌肉表情/关节动作/单运镜/负面词齐全/三候选择优/帧数实测）
**逐项过一遍**，与第 11、12 项合并执行；任一项不过，按该模板模块六的重试梯度处理。

## 二、救片八法（按镜头运动量选手段，先量帧差再动手）

| 手法 | 适用 | 要点 |
|---|---|---|
| ① 整帧替换层 | **锁定镜头**（帧差<1） | 补一帧处理好的图全片覆盖，观众零感知 |
| ② 定点模糊 | 锁定镜头的乱码文字 | 12 个矩形逐个高斯模糊，数字/波形保留 |
| ③ 掩码腐蚀改形 | 静止画面里的假液体/假泼溅 | 掩码 8 倍降采样 Min7/Max11 吃尖刺回涨成浸染，补丁淡入="正在洇开" |
| ④ 逐帧追踪贴片 | 近静止镜头里的道具补内容 | 质心逐帧插值（0.1s 采样），掩码羽化贴回；**布点程序算，不手估** |
| ⑤ 边缘暗角 | 背景有不该出现的人/物 | 左缘+对角径向渐变，把糊影吞进阴影，不裁镜 |
| ⑥ 方向反转剪除 | 运动镜头方向翻转 | 硬切掉 1-2s，接下一镜；音频 0.3s 交叉淡化（J-cut） |
| ⑦ 入画截断 | 角色提前出现在不该在的位置 | 在其入画前 1-2 帧截断镜头 |
| ⑧ 片尾卡+TTS | 补题眼/署名 | 黑底淡入+云扬配音；**音画按帧数/30 对齐**（见音频师硬判据 8） |

## 三、修 vs 重生成（决策树）

```
破绽在运动镜头里（手、脸、大幅动作）？
├─ 是 → 重生成该镜（静图锚点+动作 prompt），patch 贴不住
└─ 否（锁定/近静止）
   ├─ 破绽是"多出来的东西"（乱码/泼溅/背景人影）？→ 补丁/模糊/暗角
   └─ 破绽是"缺的东西"（道具没内容）？→ 逐帧追踪贴片
连续性错误（走位/方向/入画时机）？→ 剪辑（⑥⑦），零成本
```

## 四、修完必须重验（与初剪同一套闸）

- **逐窗 RMS**（2s 格）：计划外静音 = FAIL
- **帧数对账**：Σ逐段帧数 == 总帧数
- **AI 标识**：修片重新编码后标识会丢，**渲染时重写**（-metadata comment=AI-Generated + Deeptech-Marking=AIGC），头信息+字节层双取证
- **音画等长**：音轨时长按各视频段帧数/30 反切，累计误差必须 <0.1s
- 抽帧目检：每个修复点前后各 1 帧
