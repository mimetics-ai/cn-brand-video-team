# 入口分诊表（v1.5.7）· 客户说一句话，判走哪条

> 客户往往不知道我们有 7 条流程。**主理人听完第一句，就要判路径。**

| 客户说什么 | 走哪条 | 为什么 |
|---|---|---|
| 「不知道拍什么」「先给几个选题」 | **T1 选题** | 缺内容方向 |
| 「这条为什么火」「照这个做」 | **W7 结构复刻**（含 T2 拆解） | 有参考片 |
| 「要快」「先能发」「批量」「像开拍那样」 | **W5 快轨 K1/K2** | 要速度 |
| 「要能对外投」「要过审」「双画幅」 | **W1 精轨** | 要合规与双幅 |
| 「真人出镜但不想拍」「数字人」 | **W6 AI 真人** | 需要真人画面 |
| 「把使用说明做成视频」「截图串成片」 | **W4 截图讲解** | 素材是截图 |
| 「用吉祥物讲个步骤」「IP 动画」 | **W2 IP 动画** | 有 IP 形象 |
| 「检查这条片子有没有风险」「字幕打错了」 | **W3 纯合规复检** | 存量成片 |
| 「不知道该怎么用」 | **先问一句** | 见下 |

## 分不清时，只问一句

> 「你手上**已经有什么**？」
> - **只有产品/想法** ⇒ T1 选题
> - **有参考片** ⇒ W7
> - **有自己的素材** ⇒ 再问「先要能发的，还是要能对外投的？」⇒ W5 / W1
> - **什么都没有** ⇒ 先 T1，再谈素材

## 三条纪律

1. **不许自己猜** —— 分不清就问，猜错的代价是整条流程白跑
2. **一句话只能走一条** —— 客户说「又快又能对外投」⇒ 明确告诉他**两者不可兼得**，让他选
3. **判完要复述** —— 「我理解你要的是 X，走 Y 流程，大概 Z 时间」⇒ 客户确认再开工
