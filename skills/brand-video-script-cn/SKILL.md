# 中文品牌短片分镜脚本

产出物是**两份**：一份能给摄制与后期直接开工的分镜脚本，一份单文件 HTML 交付件。
内容质量在脚本本身，「这份脚本能不能照着拍」是唯一验收标准。

## 一、动手前必须先侦察（不许跳过）

品牌片最常见的失败不是文案差，是**新片和旧片不像一家人**——旧片是固定机位长镜头，
新片拍成快切加流行鼓组，观众认不出这是同一个品牌。

拿到需求后，先在项目里把**既有的成片和封面**找出来，抽帧看清它们的语汇：

```bash
# 找素材
ls -la <项目目录> | grep -Ei '\.(mp4|mov|jpg|png)$'
# 看规格（没装系统 ffmpeg 也不要紧，env_probe 会回落到 imageio_ffmpeg 自带的）
FF="$(python3 tools/env_probe.py --print ffmpeg)"
"$FF" -hide_banner -i "<片>.mp4" 2>&1 | grep -E "Duration|Stream"
# 每秒抽 1 帧，拼成联络图看整体（比逐帧看快得多）
"$FF" -hide_banner -loglevel error -i "<片>.mp4" -vf "fps=1,scale=480:-1" f_%02d.jpg -y
```

**要从侦察里读出这五项**，写进脚本的「创作总纲」：

| 读出什么 | 为什么重要 |
|---|---|
| 机位与运动（固定／航拍／手持） | 决定新片能不能用别的素材拼 |
| 光比与时段（日落／棚拍／阴天） | 决定补拍档期与调色基线 |
| 字幕排法（位置／字号／字体／出现方式） | 观众对「这牌子」的字幕习惯有记忆 |
| 文案调性（对句式／陈述／祈使） | 决定落版口号放在哪、会不会突兀 |
| 落版样式（logo 位置／出现动画） | 必须沿用，不要重绘 logo |

实测案例：某品牌既有片是「单一固定机位海平线日落 + 克制对句文案 + logo 居中浮现」，
并在封面有 `#03` 系列编号——这直接决定了新片应延续长镜头与留白，而非改成快剪。

## 二、分镜的五要素（缺一个就不算脚本）

每一镜必须给全，并按这个顺序排：

1. **分镜时间**——`入点 – 出点` 与时长秒数，精确到 0.1s。
   镜内若有多段（如「船坞 / 喷涂 / 整船」），再给**分段时刻**。
2. **画面描述**——可执行的拍摄指令：机位、景别、运动、光线、关键道具。
   写成「极远景固定机位：海平线，墨蓝渐橙红，太阳跃出海面，镜头极缓推（约 +3% 焦长）」，
   不要写「展现海洋的壮阔」这种无法执行的话。
3. **旁白／语音**——逐字稿 + **语气提示**（音色、重音落在哪、句间停顿几秒）。
4. **字幕**——落位（左下／居中下／右下）、层级（主字幕／署名小字）、逐字内容。
5. **音效 / BGM**——具体到「0:07 船笛长鸣 1 声（混响 2 秒）」「BPM 84 低音鼓点进入」。

再补两栏，制片端会谢你：

- **备注**——素材来源、合规提示、可信度关键点（如「喷涂段必须实拍，勿用素材库」）。
- **叙事功能**——一句话讲清这镜在全片承担什么（`把产品收益翻译成船东听得懂的四个词`）。

## 三、时长与语速：必须反算，不许写死

**中文旁白的语速基准**（有效发音字数 ÷ 秒，标点不计入时长、只算停顿）：

| 片子类型 | 字/秒 | 说明 |
|---|---|---|
| 庄重纪录片／品牌片 · **留白充分的慢节奏** | **2.5 – 3.5** | 刻意慢，靠停顿制造质感 |
| 庄重纪录片／品牌片 · **正常叙事** | **3.5 – 4.5** | ★ **2026-09-27 实测定标**：男声 `zh-CN-YunyangNeural` + rate −6% 实测 **4.01 字/秒** |
| 常规广告／电商 | 5 – 7 | 信息密度优先 |
| 极限 | > 7 | 观众听不清，别用 |

⛔ **不要用「常说的 4.6 字/秒」做反算** —— 那是快节奏播报的经验值。
本项目实测 **4.01**，直接用它反算，否则每 100 字会低估 **3.2 秒**，
14 镜累计能差出 **28 秒**（本 skill 实踩：原稿 97.0s → 实测需要 125.0s）。

做法：源数据只写**事实**（每镜逐字旁白），**派生量（时长）全部由函数反算**，并断言：

```python
RATE = 4.01        # ★ 本机实测有效语速（字/秒），不是 4.6
PAD  = 1.0         # 每镜额外呼吸垫 —— 旁白不能贴着头尾走

def cn_count(t):                      # 只数有效发音字，不数标点
    return len(re.findall(r"[\u4e00-\u9fffA-Za-z0-9]", t))

for s in SHOTS:
    s["cn"]   = cn_count(s["vo"] or s["sub"])
    s["need"] = s["cn"] / RATE
    raw = max(s["dur"], s["need"] + PAD)
    s["dur"] = math.ceil(raw * 2) / 2.0          # 向上取整到 0.5s
    assert s["cn"] == 0 or s["cn"] / s["dur"] <= 4.5, \
        f"镜{s['no']} 语速 {s['cn']/s['dur']:.2f} 超 4.5（听不清）"
```

**为什么这条不能省**：改了旁白却忘了调时长、或改了时长却忘了重算语速，
成果物表面自洽、实际配不上音。反算 + 断言会在生成阶段就把矛盾挡住。
★ **时间区间绝不许写死在源数据里**（上一支片「标称 60s 实测 77.4s」就是这个坑）。

### ★★ 均速判据：只判「逐镜超速」，不判「全片均值」

本 skill **连错过两版**，记下来避免重犯：

| 版本 | 判据 | 结果 | 错因 |
|---|---|---|---|
| v1 | `总字数 / 总时长` | 0.84「越界」 | 分母含每镜呼吸垫与刻意留白镜 |
| v2 | `总字数 / 有文本镜时长` | **仍 0.84** | **14 镜全都有文本**（3 字幕 + 11 旁白），分母换不掉 |
| **v3 正解** | **逐镜 `cn/dur ≤ 4.5`**（超速检查）；全片均值**只打印、不判** | 通过 | 「全片平均速度」在慢节奏品牌片里**本身没有意义** |

**要守的是「别超速」（说太快听不清），不是「别太慢」** —— 留白是设计。
**判据与设计意图冲突时改判据，不改设计**。
（同本项目 R19 / R35：核验判据自身也要被质疑。）

### ★ 压时长的正确顺序：先拆多句格，别调语速

每镜一句话（单句格）时长已经被 `need` 锁死，压不动。
**膨胀集中发生在「一镜塞了 2–3 句」的多句格** —— 把它们拆成独立镜次或移出本片，
是唯一不动语速、不动原文的合法手段。实测：满片台词超窗 **+35%**，全部集中在多句格。

**留白是设计，不是浪费**。开篇 6 秒只念 12 个字（2.0 字/秒）是刻意的——
纪录片质感来自「说一句，停三秒」。低语速镜要在脚本里显式标注「整段留白 3 秒以上」，
否则后期会以为你算错了而去加速。

## 四、对外表达：合规清单（成片定剪前必过）

逐条核，任何一条命中都要在脚本里写明处置方式：

1. **国旗 / 国徽 / 领导人形象**——企业宣传片具**商业广告**性质，
   《国旗法》第二十条「国旗及其图案不得用作商标、授予专利权的外观设计和商业广告」、
   《广告法》第九条「广告不得使用或者变相使用中华人民共和国的国旗」。
   **结论：品牌片全片不得出现国旗及其图案**。
   节日主题改用**色彩与数字**承载（如国庆用「红色信号旗 + 朝霞红 + 1949—2026」）。
   注意《国旗法》第九条倡导「在适宜的场合使用国旗及其图案表达爱国情感」——
   那是指非商业的公益表达，**不能拿来给商业片开脱**。
2. **广告法极限词**——「国家级／最高级／最佳／第一／唯一」等不得出现。
3. **数据须有依据**——任何具体年限、百分比、对照数值，必须有技术部门的实测依据。
   没有依据时**只作定性表述**（如「更低的阻力」「更长的防污期」），并在脚本里标注待补。
4. **素材授权**——船舶／港口／客户实拍需取得授权；画面中的第三方商标（船级社标志等）需确认是否遮挡。
5. **术语口径**——同一概念在系列片中只能有一种说法。
   本项目的实测分歧：客户口语说「长坞期」，而既有字幕口径是「更长防污期」。
   两者含义不同（坞期＝两次进坞间隔，属客户价值；防污期＝涂层有效期，属技术指标），
   **须请用户拍板统一，不许同片混用**。

法条引用前**必须联网核实原文**（条号会随修法变动，网上大量解读仍在引旧条号）。

## 五、HTML 交付件

结构（8 节，编号从 `00` 起——校验脚本要求 `00→NN` 无跳号）：

```
00 速览        ← 六镜一览 + 已定决策 + 交付前三件事（让制片端 30 秒看懂）
01 创作总纲    ← 立意 / 叙事递进 / 语汇与节奏（含反算出的语速）
02 视觉规范    ← 色板（含用量配比）/ 字体与字幕规范 / 落版
03 分镜结构总览 ← 时长占比表 + 情绪强度曲线 SVG
04 分镜详解    ← 六镜 × 五要素卡片
05 音乐与声音设计 ← 曲目规格 + 逐段 BGM（时间/段落/BPM/配器/意图）+ 混音要点
06 素材盘点与制作清单 ← 逐镜素材来源与状态 + 待补拍清单
07 合规与待确认项 ← 上节清单的落地记录
```

**情绪强度曲线是这张表之外最有信息量的一件东西**：横轴时间、纵轴强度，
标出谷底与峰值。品牌片的标准形状是「两峰一谷」——
第 4 镜左右**骤然抽空音乐**（制造远洋／孤独感），第 5 镜冲峰值。
没有谷就没有峰；这个设计要写进脚本，否则后期会把音乐铺满全程。

出完 HTML 后，**走三关校验**，不要自己肉眼看一遍就交：

- **第一关 · 结构（脚本查）**——机器能查的绝不靠人眼：标签闭合／章节编号／**表格列数（含 `rowspan`）**／
  SVG 坐标越界／无残留 Markdown。
- **第二关 · 目检（脚本查不到视觉）**——整页栅格成长图逐段看：表格**窄列折行**、**色卡浅色块看不见**、
  文字骑跨、**中文孤字行**、面积填充 `fill-opacity` 太低。
- **第三关 · 留痕**——trace／state／日志落盘，下一次能接上、别人能复核。

★ **第一关与第二关必须都做，不能相互替代。** 实测：结构自检能抓到「文字超出画布 25px」，
但「两处数字互相打架」**只有目检看得见**。

## 六、运行环境

- **不要手抄别人机器上的路径**：`python3 tools/env_probe.py` 一条命令列出 python / ffmpeg / ffprobe 的实际路径与缺失项；
  Windows 下把 `python3` 换成 `python`。
- **Python**：直接用运行本包的解释器（`python3 tools/env_probe.py --print python` 会告诉你它是谁）
- **没装系统 ffmpeg 也不打紧**：`tools/env_probe.py` 会自动回落到 `imageio_ffmpeg` 自带的可执行文件：
  `python3 tools/env_probe.py --print ffmpeg`

## 七、交付前自检（写进生成器，不靠人眼）

生成器跑完必须打印并断言：

- 各镜时长合计 == 目标秒数
- 镜数 == 需求镜数
- 旁白总字数 == 逐镜字数之和
- **逐镜语速 ≤ 4.5 字/秒**（超速检查）★ 全片均值**只打印、不判**（见§三）
- 章节数 == 预期节数
- HTML 里 `**` 残留数 == 0
- **14 镜生成提示词无一为空** + 负向提示词覆盖 15 项合规关键词
  （文字/字幕/水印/logo/商标/旗帜/国徽/地图/国界/人脸/人物/卡通/低清/模糊）

任一条不过**直接抛错停止交付**，不要「先出了再改」。

### ★ 禁用词自检的取样范围必须与「什么算违规」一致

本 skill 实踩：禁用词自检最初扫 `旁白+字幕+提示词+**note**` → **假阳性**。
原因是 note（制作备注）里为了留档写了「原稿『打破国际垄断』**已删**」，词还在 → 命中。

**正解两条一起做**：
1. **扫描范围缩到「会出现在成片上的文本」** = `vo` + `sub` + `gen`，
   排除 `note`（备注本就会引用历史文案用于留档）；
2. note 里**不要写被禁词的完整连写**，改写成「一句外资对标的强主张」这类描述；
   若必须说明，用**否定式声明**（「不得宣称打破国际垄断」）——

★ 否定式声明里的词**不应算命中**。**判据的取样点必须避开「说明性/框架性文字」**。

附带坑：序数词「第一段/第二段」与极限词「第一」**同形**，扫提示词时会误伤
→ 提示词里改用「开场…转到…收在…」描述分镜顺序，别用序数词。

### ★ 自检全绿 ≠ 没有缺陷：HTML 交付件必须目检

生成器的结构自检只能证明「标签闭合、编号不跳、无残留 Markdown」，
**证明不了版面**。本 skill 实测：自检全绿的情况下，视觉层仍有两处真缺陷 ——

1. **表格窄列折行**：镜次列 `02 + 03` 折成 `02 +` / `03` 两行
   → 列宽 70→110px + 该列 `white-space:nowrap`；
2. **SVG 段落标签重叠**：窄段（宽度 < 62px）的段落名压住时长文字
   → 窄段把「名称」上移一行、「时长」下移一行，竖向错开。

**做法**：无头浏览器栅格化整页 → 裁底部空白 → 纵向切 8 片 → **逐片目检**。
```bash
msedge --headless=new --disable-gpu --hide-scrollbars \
  --window-size=1200,22000 --screenshot=chk/page.png \
  --virtual-time-budget=6000 "file:///<abs-path>.html"
```
★ **`--window-size` 高度要给足**（本件 14,286px 内容高，给 22,000 才截全）；
★ 截图 `resize()` 时**只传高、宽用 `im.width`**，同时传宽高会把横向也压扁（实踩）。

## 八、素材生成通道：AgentEarth（外部 MCP）与内置 VideoGen

分镜确认后要逐镜出素材，两条通道都实测过，**先确认哪条真的可用**。

### 8.1 AgentEarth 是 Connector（外部 MCP），新装后**不会自动生效**

- 配置落在 `~/.workbuddy/mcp.json`，服务名 `agentearth`，`type: "http"`，
  `headers.X-Api-Key` 写的是 `AGENT_EARTH_API_KEY`。
  （凭据由 WorkBuddy 从 Token form 注入 MCP 连接，**skill 本身看不见 API key**。）
- 暴露 5 个工具：`GetAccountOverview` / `RecommendTools` / `ListTools` /
  `GetToolDetail` / `ExecuteTool`。
- **★ 使用流程**：`RecommendTools({query})` → 读候选的 `tool_url`/`description`/
  `input_schema`/`credit` → 需 ID 类参数时先用 `associated_tools` 里的伴随工具 →
  `ExecuteTool({tool_url, params})`。
  ⛔ **`tool_url` 必须原样透传**，禁止修改/重编码/重组。
- **★ 成功判据是 `isError` 字段**，**不是** `error_no == 0`
  （后者只对 AgentEarth 原生查询工具成立，对 `ExecuteTool` 透传结果不成立）。
- 能力面：聚合即梦 Dreamina/Seedream/Seedance、可灵 Kling、通义万相、混元、
  MiniMax/海螺、智谱 GLM、Google Veo、OpenAI GPT Image/Whisper、SD、FLUX、
  HeyGen、ElevenLabs —— 覆盖生图 / 图生视频 / 文生视频 / 数字人口播 / 配音 / BGM / 音效。

**★ 挂载判据（缺一即未生效，别凭「配置写了」就当作可用）**：

```bash
cat ~/.workbuddy/mcp-approvals.json          # 空 {} = 未授权
python -c "import json,io;d=json.load(io.open(r'<home>/.workbuddy/mcp-tool-list.json',encoding='utf-8'));print(len(d.get('entries',{})))"
```

- `mcp-approvals.json` = `{}` → 用户在**连接器管理页还没点「信任」**；
- `mcp-tool-list.json` 里那几组工具**不含 agentearth** → 工具没挂上（即便 `mcp.json` 已配好）；
- 最终判据：**用 ToolSearch 搜一次**。搜不到就是不可用，别猜。
