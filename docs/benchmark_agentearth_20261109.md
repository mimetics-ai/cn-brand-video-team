# AgentEarth 考察报告（2026-11-09 · 配音/口型/原生带声能力对标）

> 源头：外部「lib 电影制作」项目的两份实测卡（`11_AgentEarth配音与视频最小实测报告` / `12_Vidu原生带声配方与扩产制作卡`），
> 经用户**作品层正面确认**（「第一个做得挺好的啊」——该项目 v0/v2 两版均被否决后首次通过）。
> 本文只收编流程与方法，不绑定具体工具账号。

## 一、测出了什么（对白镜三链路）

| 链路 | 做法 | 实测结论 |
|---|---|---|
| **A 原生带声（优先）** | 图生视频开 `audio=true`，**台词原文写进 prompt 引号里** | 模型原生生成画面＋中文同期声；盲转写逐字命中，自带两处表演停顿；机位 10/10 帧锁住；嘴区差/全帧差 4.35（变化集中在嘴） |
| **B 配音＋口型同步（兜底）** | TTS 配音 + LatentSync 类工具对齐已有画面 | 口型最明显（嘴区差 24.95）；代价：脸部重绘伪影＋继承原素材缺陷（自主推近）＋音轨降规格 16 kHz mono 需重采样 |
| **C 画外 TTS（最后手段）** | 后期贴配音，无口型 | 即「旁白感」——被用户连续否决的形态，对白镜禁用，只许旁白镜用 |

**优先级：对白镜 A > B > C；旁白镜仍走既有 TTS 通道。**

## 二、原生带声提示词配方（四成分缺一不可）

1. **镜头锁系列**：`Fixed locked-off camera`＋禁推近/禁平移/禁切/禁换人/禁新增物件；
2. **台词原文放进引号**（不是后期贴音，是让模型"说"）；
3. **口型显式指令**：`lips open and close clearly in sync`；
4. **纯人声声明**：`audio contains only this one Chinese male speaking voice, no background music`。

## 三、对白镜验收方法学（工具无关，重点收编）

1. **盲转写命中**：把成片音轨送语音识别，**不喂提示词、不喂答案**，判据＝逐字命中台词＋`language=zh`＋词级时间戳完整；
2. **机位锁定量**：2 fps 抽帧全帧差均值 **< 6** 判"锁住"（对照：失效样本 9.53）；
3. **口型定量**：**嘴区差 / 全帧差 > 3** 判"变化集中在嘴"（对照：画外 TTS 形态 ≈2.6）；
4. **首帧一致性**：与输入参考图同人物/同服装/同光线；
5. **音轨规格**：交付级＝48 kHz stereo 原生；16 kHz mono（口型同步链路常见输出）必须重采样；
6. **时长对齐**：模型输出 5.04 s 类非整时长，**裁到整秒对齐节奏窗**，余量补有意停顿/反应镜，不用定格硬凑。

## 四、配音表演层（TTS 通道能力，有则必用）

- 支持内联表演标签的通道：`[pause]`（实测生成 0.5 s / 0.75 s 真实停顿）、`[laugh]`、`[sigh]`；包裹标签 `<whisper>`、`<slow>`；
- 平铺播报＝「旁白感」的根源之一；对白 TTS 优先选支持表演标签的通道，无标签通道至少做【情绪】→rate/pitch 映射（既有规则不变）。

## 五、成本与边界（外推纪律）

- 原生带声按秒计费（实测档位 185 credits/s，**720p 与 1080p 同价 ⇒ 直接开 1080p**，规格一次到位）；
- 口型同步按条计费（≤40 s 一口价），适合把既有素材"救"成说话镜；
- 60 集纯原生带声外推 ≈ 95 万 credits——**混合路线**（对白近景走 A、其余走 B/非对白镜走常规链路）才是可扩产形态，但跨镜一致性未测前不许批量；
- 单镜能力验证 ≠ 成片成立：长叙事、跨镜一致性、多角色对白、笑点，均未因单镜成功而解锁。

## 六、踩坑留痕

- 某 WAV 返回流式头，`nframes=0x7FFFFFFF`，`wave` 模块读出 2 万秒假值 ⇒ **时长一律用 ffmpeg 解码实测，不信 WAV 头**（同「Duration 不可信 ⇒ frames/fps」口径）；
- 某转写工具 Bad Request 两连，换工具一次过 ⇒ 单工具两败即换道，不重试浪费。

## 七、整集扩产巡检补记（六巡 · 2026-11-09 下午）

> 源头：同一外部项目当日下午的整集扩产实测（阶段 1→2→3 逐阶段验收）。
> 只收编流程与判据，不含任何账号/预算数值。

**链路升级结论**：原生带声从「单镜样片成立」升级为「整集主链路走通」——13 镜 100% 重新生成拼成 86 s 竖屏整集，其中 8 镜原生同期中文对白＋1 镜原生笑声；抽镜盲转写 8/8 逐字命中，成片混音整轨再转写一次、全部台词按序读出。画外 TTS 从主声道降级为空镜/画外音专用。

**验收判据修正（重要）**：跨镜切点的「帧差倍数」判据**作废**——正规景别切换本来就会产生高切点帧差，把 4.84 倍误判为「串镜」是假阳性。改判据：
- 跨镜一致性＝同人物/同服装/同光线/构图连续（接触表逐行人工判读）＋切点**亮度跳变**阈值；
- 转场用 0.25 s 交叉溶解后，切点平均亮度跳变从硬切版 40.0 降到 6.97（最大 15.03）——亮度跳变才是「闪跳感」的直接度量。

**新能力实测（阶段 2 四个零验证项）**：
1. **女声可控**：模型无 voice 参数，纯靠 prompt 自然语言指定成年女声即可成立；判据＝自相关 F0（中位数 ≈267 Hz 判女声）＋长台词（27 字）盲转写逐字命中。
2. **双人指定说话人＝部分可控**：只能靠提示词＋首帧构图指定谁开口，可靠性随画面人数上升而下降。定量方法：2 fps 抽帧分别测左右嘴区帧差——干净通过样本＝说话侧均值 7.05 / 非说话侧 1.56 / 背景区 4.48（说话侧显著高于非说话侧）；**失败模式＝模型自主缓慢推近，整体位移污染嘴区帧差，此时该判据失效**⇒ 说话人隔离判据以「机位锁先验证」为前提。
3. **多参考图 mix 不作主链路**：身份锁得住，但服装/场景/光线整体漂移，与其余镜头不属于同一空间 ⇒ 起始帧锚定仍是主线路线。
4. **长台词**：8 s 档原生对白成立，无截断。

**踩坑留痕（新）**：
- 个别镜输出 720p（其余 1080p）⇒ 逐镜 spec 必须逐条核分辨率，混规格成片需统一上采样并在交付报告如实标注「该镜略软」；
- 各镜音频头部静音 0.1–2.3 s 不等 ⇒ 混音前逐镜测 `silenceHeadS` 并对账，不能假设同期声从 0 帧起；
- 修复一类失败（制服人员走进画面）后可能引入另一类（缓慢推近）⇒ 每次改 prompt 后必须全量重跑验收，不能只看被修项。

**阶段化止损纪律（固化）**：整集扩产按「阶段 1 关键风险项小额验证 → 阶段 2 边界能力实测 → 阶段 3 全量生成 → 阶段 4 验收交付」推进，每阶段独立验收、不达标即止损；**未通过阶段 1 跨镜验证前禁止批量生成**。

## 九、v3 交付判读：技术全过、内容没过（2026-11-09 13:1x · 同项目）

对方把 86 秒整集改为 13 镜全部原生带声重生成，结论分两层：

### 技术层：全过

| 指标 | 结果 |
|---|---|
| 重生成画面 | 83 s（另 3 s 片尾卡），旧画面复用 0 帧 |
| 原生同期对白镜 | 8 镜对白＋1 镜原生笑声（`audio=true`）；4 空镜走画外音/音效 |
| 台词盲转写 | 逐镜抽查 8/8 逐字命中；**最终混音整轨再转写一次，11 句按序全读出** |
| 切点亮度跳变 | 12 处 0.25 s 交叉溶解后 **平均 6.97（峰值 15.03）**；硬切版 40.0（峰值 92.3） |
| 规格 | 86.000 s / 1080×1920 / 24 fps / 48 kHz stereo，峰值 0.89 无削波 |
| 静音占比 | 2.0%（v0 61.8% / v2 6.7%），连续静音上限 0.50 s |

### 内容层：没过

客户原话：「**做完了，还是满意的结果，只是剧情一点不好笑。**」
⇒ 技术验收全过＝交付物合格；内容不成立＝片子不合格。
死因不在生成、不在配音、不在剪辑，在**剧本用「设定说明」代替了「戏」**（解释规则多、事件与反转少）。
收编 → 主理人 **Phase 1.6 内容成立闸**（盲测试看＋铺垫-转折-落点＋解释句占比 >30% 退回），
并写入 `KNOWN_LIMITS.md` 第 8 条：AI 判断不了好不好笑，只能真人试看。

> 一句话总结这一仗：**流程能把「不像视频」修成「人在说话」，修不了「不好笑」。**

## 十一、能力边界总账卡（22 号卡 · 11-10 上午判读）

对方把 01–21 号卡全部实测结论汇总成《各工具实际能力边界对照》，三条做法比内容本身更值得收：

1. **四级能力标记法**：✅实测可做（有样本有数字可复现）/ ⚠️部分可控（有通过也有失败）/ ❌实测不支持 / ⬜仅发现未实测——
   **写不出证据的一律降级为 ⬜**，「理论上应该可以」不许用来填空；
2. **未验证清单明示在边界外**：只在工具目录里出现过、没提交过任务的能力，单独列节声明「不得当作可用能力」；
3. **能力边界只到技术层**：工具决定「人是否在说话/机位锁不锁得住」，第七节单列「所有工具共同的上界」——
   无镜头语言、无喜剧节奏决策、无作品层判断；**同一套工具做出过被认可的 5 秒样片，也做出过被判不可笑的 64 秒全集——变量不是工具**。

本包动作：④级标记法收入本节作能力文档撰写规范；「运镜/反打/反应镜/群戏＝所有生成工具都没有」补进 `KNOWN_LIMITS.md` 第 4 节；
「提示词与首帧逐项对齐」「禁止文字是后期纪律＋修补顺序」「cv2 中文路径」补进 `agents/footage-editor.md`（并入本包 v1.10.0 备弹，未上传不升号）。

## 十二、能力形状（22 号卡第十节 · 11-10 上午 · 全录）

> 触发：用户问「这套组合到底适合做什么」。
> 判据一句话：**它生成「一个人把一段文字说出来」，不生成「一件事在画面里发生」——越像播报，越成立；越像戏，越不成立。**

三条实测约束推出适配范围（不是观感评价）：

1. 单次 ≤16 s ＋ 无运镜 ⇒ 内容单位只能是**一句**，不能是**一场**；
2. 无反打/反应镜/可靠双人指定说话人 ⇒ 画面只能一个主体，**冲突必须发生在文字内部**；
3. 人物不笑、动作幅度小、信念感不破 ⇒ 天生**陈述/宣告/记录**调性，不是互动/对抗/失控。

| 档 | 类型 | 依据 |
|---|---|---|
| **高** | 单人陈述式竖屏短内容：判词、告示、证词、播报、语录 | 固定机位、单人、原生同期声、锁首帧、5–8 s 五项实测通过 |
| **高** | 档案/卷宗/编号条目式系列 | 13 镜跨镜一致性已验证；首帧可复用，每集只换台词，**边际成本递减** |
| **高** | 品牌/知识型一句话口播 | 1080×1920/24 fps/48 kHz 一次到位，字幕本地解决 |
| **高** | 克制的智性反讽、冷面荒诞短句 | 「人物一本正经」是模型自带特性；**产出是会心，不是笑出声——不能按喜剧验收** |
| 中 | 诗/格言/经文可视化；教学/解释卡片 | 静慢单人朗读适配；知识密度压字幕，受时长上限 |
| **不适应** | 喜剧短剧、连续剧情、群戏/对手戏、动作/身体喜剧，及一切靠反应镜或节奏剪辑成立的形态 | 本文第七节共同上界；15/20 已实测不成立 |

**反直觉要点**：《本县无贼》的**题材**（卷宗、律条）高度适配——坏在**把它当喜剧拍**。
改成「一集一条档案、只念一句判词」的陈列式系列即落回能力形状内。**换内容类型能救，换工具救不了。**

**成本形状限定类型**：185 credits/s ⇒ 适配形态还须**短、少镜、首帧可复用**；
60 集 × 90 秒 ≈ 95 万 credits，成本上先不成立。

**边界声明**：能力形状匹配 ≠ 作品层验证——「日更口播有没有人看」「档案式系列能不能留住观众」一次都没验过。
**工具适配 ≠ 内容成立。**

**本包落点（v1.11.0）**：Phase 1.5a 加「横评前先判链路能力形状」；
audio-designer 对白镜规则加适配分档（第 10 条）；KNOWN_LIMITS 第 8 条补「题材适配 ≠ 类型适配」。
