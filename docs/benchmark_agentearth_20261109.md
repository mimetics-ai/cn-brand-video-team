# AgentEarth 考察报告（2026-11-09 · 配音/口型/原生带声能力对标）

> 源头：外部「lib 电影制作」项目的两份实测卡（`11_AgentEarth配音与视频最小实测报告` / `12_Vidu原生带声配方与扩产制作卡`），
> 经用户**作品层正面确认**（「第一个做得挺好的啊」——该项目 v0/v2 两版均被否决后首次通过）。
> 本文只收编流程与方法，不绑定具体工具账号。

## 一、测出了什么（对白镜三链路）

| 链路 | 做法 | 实测结论 |
|---|---|---|
| **A 原生带声（优先）** | 图生视频开 `audio=true`，**台词原文写进 prompt 引号里** | 模型原生生成画面＋中文同期声；盲转写逐字命中，自带两处表演停顿；机位 10/10 帧锁住；嘴区差/全帧差 4.35（变化集中在嘴） |
| **B 配音＋口型同步（兜底）** | TTS 配音 + LatentSync 类工具对齐已有画面 | 口型最明显（嘴区差 24.95）；代价：脸部重绘伪影＋继承原素材缺陷（自主推近）＋音轨降规格 16 kHz mono 需重采样 |
| **C 画外 TTS（最后手段）** | 后期贴配音，无口型 | 即「旁白感」——被用户连续否决的形态，对白镜禁用，只许旁白镜用 |

**优先级：对白镜 A > B > C；旁白镜仍走既有 TTS 通道。**

## 二、原生带声提示词配方（四成分缺一不可）

1. **镜头锁系列**：`Fixed locked-off camera`＋禁推近/禁平移/禁切/禁换人/禁新增物件；
2. **台词原文放进引号**（不是后期贴音，是让模型"说"）；
3. **口型显式指令**：`lips open and close clearly in sync`；
4. **纯人声声明**：`audio contains only this one Chinese male speaking voice, no background music`。

## 三、对白镜验收方法学（工具无关，重点收编）

1. **盲转写命中**：把成片音轨送语音识别，**不喂提示词、不喂答案**，判据＝逐字命中台词＋`language=zh`＋词级时间戳完整；
2. **机位锁定量**：2 fps 抽帧全帧差均值 **< 6** 判"锁住"（对照：失效样本 9.53）；
3. **口型定量**：**嘴区差 / 全帧差 > 3** 判"变化集中在嘴"（对照：画外 TTS 形态 ≈2.6）；
4. **首帧一致性**：与输入参考图同人物/同服装/同光线；
5. **音轨规格**：交付级＝48 kHz stereo 原生；16 kHz mono（口型同步链路常见输出）必须重采样；
6. **时长对齐**：模型输出 5.04 s 类非整时长，**裁到整秒对齐节奏窗**，余量补有意停顿/反应镜，不用定格硬凑。

## 四、配音表演层（TTS 通道能力，有则必用）

- 支持内联表演标签的通道：`[pause]`（实测生成 0.5 s / 0.75 s 真实停顿）、`[laugh]`、`[sigh]`；包裹标签 `<whisper>`、`<slow>`；
- 平铺播报＝「旁白感」的根源之一；对白 TTS 优先选支持表演标签的通道，无标签通道至少做【情绪】→rate/pitch 映射（既有规则不变）。

## 五、成本与边界（外推纪律）

- 原生带声按秒计费（实测档位 185 credits/s，**720p 与 1080p 同价 ⇒ 直接开 1080p**，规格一次到位）；
- 口型同步按条计费（≤40 s 一口价），适合把既有素材"救"成说话镜；
- 60 集纯原生带声外推 ≈ 95 万 credits——**混合路线**（对白近景走 A、其余走 B/非对白镜走常规链路）才是可扩产形态，但跨镜一致性未测前不许批量；
- 单镜能力验证 ≠ 成片成立：长叙事、跨镜一致性、多角色对白、笑点，均未因单镜成功而解锁。

## 六、踩坑留痕

- 某 WAV 返回流式头，`nframes=0x7FFFFFFF`，`wave` 模块读出 2 万秒假值 ⇒ **时长一律用 ffmpeg 解码实测，不信 WAV 头**（同「Duration 不可信 ⇒ frames/fps」口径）；
- 某转写工具 Bad Request 两连，换工具一次过 ⇒ 单工具两败即换道，不重试浪费。
