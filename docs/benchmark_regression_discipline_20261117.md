## 三、C-03／C-07／C-08：判据跨版本复算零漂移

**四步做法**：输入路径写死一致（避免各包样例差异被误读成判据差异）；
执行体用各代包内检查器（不拿当前版本跑旧包）；当前版本另跑一遍作独立基准；
剔除时间派生字段后固定键序序列化比 md5。

**防互相自证**：十三巡基线等于十二巡 current/defective，十四巡基线等于十二巡 current/failing，
两路基线互不相等——若相等，应先查输入串线，不应直接宣布复算成功。

**书写契约**：`scannedAt`／`exportedAt`／`packedAt`／`fileDigests[].fnv1a` 等派生项逐项登记剔除原因；
固定时钟只作显式通道，默认分支仍走真实时钟。某代不支持该通道时分两类：
静默忽略（rc=0，输出回落原有形状）与报错退出（rc=2，带值 flag 被当路径），
逐条附 rc／stdout 前缀／stderr 原文，不得写「还没做」。

**本包缺口**：v1.8.1→v1.13.0 六版只规定「判据冻结件不可增删改」，
没有跨版本复算证明。版本迭代时若判据被无意改动，现状靠人眼 review 发现。

## 四、C-04／C-05／C-06：回归资产、清单与覆盖矩阵

### C-04 真 FAIL 输入作回归资产

真 FAIL 输入（删 image 节点，inputHash `f9e49db6`，样片闸 FAIL 3/4）存为基线资产。
九条附加通道（`--lessons`／`--evidence*`／`--pack-manifest`／`--fixed-time` 等叠加）
下基段仍逐字节相等，FAIL 结论未被洗白。

本包缺口：盲评 FAIL 判据齐备（20 项硬 9 软 11、8 维 ≥32），
但历史 FAIL 轮次输入未作回归资产；工具链迭代时没有「FAIL 仍是 FAIL」的复算保障。

### C-05 清单驱动与跨轮漂移

机器可读清单含 steps／currentValues／frozenArtifacts／noReplay／requiredGroups，
runner 从清单读 steps 构造命令。**新增闸不写进清单，清单自检判 FAIL**——
把「每轮必跑」从人记变成机器强制。

跨轮漂移：冻结上轮清单副本，逐字段 diff 本轮清单，列出哪些当前值变了、是否同轮随动。
「必须随动」与「必须不随动」双向核验：引用件当前值逐条比对，历史留痕 needle 逐条比对
（上轮终态仍记旧词表条数——历史不随动本身也是判据）。
五种坏副本（退回旧值／删 step／label 不随动／删冻结件／未登记漂移）都应判 False。

本包缺口：铁律 B 靠执行者自觉＋事后抽查；清单化后变成每次回归自动核验项。

### C-06 三输入覆盖矩阵

clean `b4407d01`（4/4）、defective `d90529f8`（4/4，缺陷落在 lessons 一类）、
failing `f9e49db6`（3/4 样片闸 FAIL）三类输入 × 三条通道聚合成单一索引。
无覆盖格写 `NOT_COVERED_BY_THIS_CHANNEL_RUN`，附 status／stateSource／verbatim 三件；
检索标识写「全文检索 inputHash=xxx，命中 0 条」。
**无覆盖是已核查的覆盖事实，不等于待办，也不判故障。**

## 五、C-09：验证不采信被测对象自报

| 项 | 内容 |
| --- | --- |
| 现象 | 在线轮调账本桥接工具恒返回 `entries:0` |
| 独立真值 | 另直连端点返回非空 `entries:[...]`，两轮均 54 条、credits 1056 |
| 根因 | 桥读 `l.data.ledger`，端点给的是 `entries`——字段名错读，数据并未缺失 |
| 纪律 | 桥／代理结论须另走独立通道比对条数与关键字段；读不到按解析失败处置，不回落成空数据 |

与 v1.13.0 已收 C-01 的关系：C-01 管验证动作别污染被测对象，C-09 管验证结论别只听被测对象自报。
两条是孪生，故作 9.3 补强而非另立章节。
